# optics-simulation

STL-based PET bottle caustic simulation and pattern optimization.

This repository develops a modular Python pipeline for:

- STL ingestion and mesh quality checks
- baseline 3D ray tracing
- incident-angle risk scanning
- caustic contribution mapping
- adaptive dimple pattern generation
- optical and simplified thermal risk metric validation

The project does not model or optimize ignition. Results are interpreted as reduction of local caustic and thermal-risk metrics caused by transparent PET bottle optics.
